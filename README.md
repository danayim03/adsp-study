# ADsP 스터디룸

데이터분석 준전문가(ADsP) 시험을 준비하기 위한 인터랙티브 학습 사이트입니다.

**Live site: https://danayim03.github.io/adsp-study/**

## What's inside

- 23 short sections across 1과목 데이터 이해, 2과목 데이터 분석 기획, 3과목 데이터 분석
- Concept cards that ask you to recall first, then reveal the answer and an exam point
- A quiz for every section (no need to finish the lesson first)
- Mixed quiz, mistake review, and a 50-question mock exam with a 90-minute timer
- Small calculators for the confusion matrix and association rules

## Notes

- Progress is saved in your own browser only (localStorage). It does not sync across devices.
- Everything runs in a single static file, `index.html`. There is no build step.
- For personal study use.
